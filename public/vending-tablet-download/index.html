Tavari Vending — Tablet app

Install this app on the vending machine tablet. It shows the Tavari kiosk and controls the machine over RS485 — no manufacturer app required.

  1. If Tavari Vending is already installed, uninstall it first (Settings → Apps).

  3. Tap the file to install (allow "Install unknown apps" for Chrome or Files if Android asks).
  4. Open Tavari Vending and use Test vend to confirm the motor runs.
